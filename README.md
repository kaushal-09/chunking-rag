# chunking-rag

This repo has the code and results for our NLP poster at the University of Trier (Kaushal Oza and Varshini Naguvanahalli Govindaraju). We checked whether a stronger embedding model changes how much chunking matters in RAG, using four chunkers and two embedders on 800 KILT-NQ questions with a fixed 1,000-token context and Qwen2.5-3B-Instruct as the reader. It mostly doesn't: no chunker difference holds up after correction, and most answers are lost in the reader rather than in retrieval. The scripts in `scripts/` run the pipeline, with all settings in `config.py`. Every run is saved per question in `data/runs`, so `python scripts/05_analyze.py` and `python scripts/07_verify.py` reproduce the poster's numbers without the 2.5 GB corpus, chunk files and indexes, which aren't included here but can be rebuilt with scripts 01 and 02. The poster source is in `poster/` (figures from `scripts/06_poster_figures.py`), and `METHODS.md` has the longer write-up, including the order to run everything in.
